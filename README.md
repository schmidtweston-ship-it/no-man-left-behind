No Man Left Behind is a small family utility page for Weston and his dad. Open it on the phone, enter the door code (default 7391; change it under Set up on that device), save Weston’s number once, and use the three buttons. Talk and requests leave through the phone’s own Messages app. Nothing is stored on a server.
